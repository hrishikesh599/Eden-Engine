# Eden-Engine
a project that started from a simple plant growing when key pressed system to an simulation
this project had taken a lots of effort and time!!

what this project is?
  this is a simulation of plants or a garden where the user is able to plant seeds my click on the ground using mouse, it will plant a seed, then slowly germination starts, time could be fast rewinded.
   as in real life the plants need water to grow properly so, the plant should be watered or the plant slowly dies, the plants fight for the sunlight
   does photosynthesis, store energy etc,
   taller plant absorb more sunlight and water thus smaller plants near it gets less,and each plants as randomly grow branches etc..
   most important feature DNA STRUCTURE:
     the plants have a dna sequence where their 
     * plant growth rate
     * branch chance
     * leaf size
     * flower hue
     * strength
     * maximum height
     are controlled, each time a seed is planted their dna sequence is created making biodiversity
     I also experimented with inheritance where dropped seeds reused parent DNA values. This made ecosystems slowly evolve over time.
     FEATURES :
        * click to plant seed
        * press 'W' and use mouse to water plants
        * time speed adjustment
        * day/night cycle
        * wind
        * fireflies
        * DNA sequencing
        * photo synthesis
        * plant dies if no water or sunlight
